# 03 — Forma Studio | Creative Branding Agency Template

A neo-brutalist creative branding agency landing page featuring bold borders, offset shadows, a live marquee strip, and interactive portfolio filtering by **PixelNestByNS**.

---

## Design Direction
- **Style:** Neo-Brutalist & Avant-Garde Creative Studio
- **Color Palette:** Warm Bone `#FBF8F3`, Pitch Ink `#161616`, Vermilion `#FF4D29`, Electric Cobalt `#1D4ED8`, Butter Yellow `#FFE169`
- **Typography:** `Space Grotesk` (Display), `Instrument Serif` (Editorial Italic), `DM Sans` (Body)

---

## Included Sections & Features
1. Sticky 2px-bordered navigation bar with animated marquee ticker
2. Full-width typographic hero with tilted studio sticker badge
3. **Interactive Filterable Portfolio Grid** (`All`, `Packaging`, `Print & Identity`, `Digital`)
4. 4-Step Studio Method cards
5. Split-screen **Capabilities Accordion**
6. Sample Collaborator Voices (editable placeholders)
7. High-contrast Project Brief Form + Footer credit: `Website Template by PixelNestByNS`

---

## Quick Setup
1. Open `index.html` locally in your browser.
2. Customize brand copy, sample quotes, and contact info in `index.html`.
3. Update colors/borders in `style.css` (`:root`).
4. Replace images inside `assets/`:
   - `assets/portfolio-packaging.jpg`
   - `assets/portfolio-editorial.jpg`
   - `assets/portfolio-digital.jpg`
